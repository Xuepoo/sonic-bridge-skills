# SonicBridge Skills 

智能体音乐审美与物理转译技能库。本仓库定义了配合 `sonic-bridge` 听觉引擎使用的 AI Agent 技能描述规范，包含 LRMD (LLM-Readable Music Descriptor) 的解析、同频听歌伴读与乐理分析能力。

AI Agent Music Aesthetic and Physical Translation Skills Repository. This repository defines the AI Agent skill specifications designed to work with the `sonic-bridge` listening engine, enabling LRMD (LLM-Readable Music Descriptor) parsing, co-listening companionship, and musicological analysis.

## 📂 技能目录 (Skills Directory)

* **[audio-analysis](file:///mnt/data/Workspace/Projects/SonicBridge/sonic-bridge-skills/audio-analysis/SKILL.md)**: 
  * **中文**：通过 `sonic-bridge` 命令行对本地音频文件进行时域、频域、和弦、瞬态检测，并输出 LRMD 审美报告。
  * **English**: Perform temporal, spectral, harmonic, and transient analysis on local audio waves via the `sonic-bridge` CLI, producing standardized LRMD aesthetic reports for pure-text LLMs.
